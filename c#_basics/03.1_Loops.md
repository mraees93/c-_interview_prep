# C# and TypeScript Collection Loops Reference

## 1. Fixed Arrays (`T[]` / `TypedArray`)

### C#
```csharp
// Fixed-size initialization
int[] numbers = new int[3] { 10, 20, 30 };

// Option A: Standard for-loop (Best for performance and index mutation)
for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(\$"Index: {i}, Value: {numbers[i]}");
}

// Option B: foreach loop (Cleanest for read-only access)
foreach (int val in numbers)
{
    Console.WriteLine(val);
}
```

### TypeScript Equivalent
```typescript
// Typed arrays mimic C#'s fixed-allocation native memory boundaries
const numbers = new Int32Array([10, 20, 30]);

// Option A: Standard for-loop
for (let i = 0; i < numbers.length; i++) {
    console.log(`Index: ${i}, Value: ${numbers[i]}`);
}

// Option B: for...of loop
for (const val of numbers) {
    console.log(val);
}
```

## 2. Dynamic Lists (`List<T>` / `Array []`)

### C#
```csharp
List<string> names = new List<string> { "Alice", "Bob" };

// Option A: Standard foreach loop
foreach (string name in names)
{
    Console.WriteLine(name);
}

// Option B: LINQ ForEach expression method
names.ForEach(name => Console.WriteLine(name));
```

### TypeScript Equivalent
```typescript
const names: string[] = ["Alice", "Bob"];

// Option A: for...of loop
for (const name of names) {
    console.log(name);
}

// Option B: Native array .forEach prototype method
names.forEach(name => console.log(name));
```

## 3. Dictionaries (`Dictionary<K,V>` / `Map<K,V>`)

### C#
```csharp
Dictionary<string, int> ages = new Dictionary<string, int>
{
    { "Alice", 30 },
    { "Bob", 25 }
};

// Option A: Destructuring KeyValuePair items directly
foreach (KeyValuePair<string, int> kvp in ages)
{
    Console.WriteLine(\$"Key: {kvp.Key}, Value: {kvp.Value}");
}

// Option B: Explicitly looping through keys only
foreach (string key in ages.Keys)
{
    Console.WriteLine(key);
}
```

### TypeScript Equivalent
```typescript
const ages = new Map<string, number>([
    ["Alice", 30],
    ["Bob", 25]
]);

// Option A: Destructuring key-value array entry pairs
for (const [key, value] of ages) {
    console.log(`Key: {key}, Value: {value}`);
}

// Option B: Looping through keys only
for (const key of ages.keys()) {
    console.log(key);
}
```

## 4. HashSets (`HashSet<T>` / `Set<T>`)

### C#
```csharp
HashSet<int> continuousIds = new HashSet<int> { 101, 102, 101 }; // 101 auto-deduplicates

// Option A: Standard foreach execution iteration
foreach (int id in continuousIds)
{
    Console.WriteLine(\$"Unique ID: {id}");
}
```

### TypeScript Equivalent
```typescript
const continuousIds = new Set<number>([101, 102, 101]);

// Option A: for...of loop
for (const id of continuousIds) {
    console.log(`Unique ID: ${id}`);
}

// Option B: Array conversion helper loop
Array.from(continuousIds).forEach(id => console.log(id));
```

## 5. Queues (`Queue<T>` / Custom Array Engine)

### C#
```csharp
Queue<string> logQueue = new Queue<string>();
logQueue.Enqueue("Event_A");
logQueue.Enqueue("Event_B");

// Option A: Standard destructive processing loop (Drains queue)
while (logQueue.Count > 0)
{
    string log = logQueue.Dequeue();
    Console.WriteLine(\$"Processing: {log}");
}

// Option B: Non-destructive observation loop (Keeps items inside queue)
foreach (string log in logQueue)
{
    Console.WriteLine(\$"Inspecting: {log}");
}
```

### TypeScript Equivalent
```typescript
const logQueue: string[] = [];
logQueue.push("Event_A"); // Enqueue operation
logQueue.push("Event_B");

// Option A: Standard destructive processing loop (Drains array)
while (logQueue.length > 0) {
    const log = logQueue.shift(); // Dequeue operation. Warning: shift() is O(N) in JS!
    console.log(`Processing: ${log}`);
}

// Option B: Non-destructive observation loop
for (const log of logQueue) {
    console.log(`Inspecting: ${log}`);
}
```

## 6. Stacks (`Stack<T>` / Array `.pop()`)

### C#
```csharp
Stack<string> pageHistory = new Stack<string>();
pageHistory.Push("IndexPage");
pageHistory.Push("Dashboard");

// Option A: Standard destructive LIFO trace processing loop
while (pageHistory.Count > 0)
{
    string page = pageHistory.Pop();
    Console.WriteLine(\$"Popped history layer: {page}");
}

// Option B: Non-destructive trace loop
foreach (string page in pageHistory)
{
    Console.WriteLine(\$"Trace visualization path: {page}");
}
```

### TypeScript Equivalent
```typescript
const pageHistory: string[] = [];
pageHistory.push("IndexPage"); // Push operation
pageHistory.push("Dashboard");

// Option A: Standard destructive LIFO trace processing loop
while (pageHistory.length > 0) {
    const page = pageHistory.pop(); // Pop operation (O(1) execution)
    console.log(`Popped history layer: ${page}`);
}

// Option B: Non-destructive loop (Iterates elements from bottom to top)
for (const page of pageHistory) {
    console.log(`Trace visualization path: ${page}`);
}
```

## 7. Linked Lists (`LinkedList<T>` / Node References)

### C#
```csharp
LinkedList<string> trackList = new LinkedList<string>();
trackList.AddLast("Node_Root");
trackList.AddLast("Node_Tail");

// Loop mechanic: Reference pointer iteration starting at First entry
LinkedListNode<string> current = trackList.First;
while (current != null)
{
    Console.WriteLine(\$"Node runtime content: {current.Value}");
    current = current.Next; // Iterates pointer to next connected memory instance
}
```

### TypeScript Equivalent
```typescript
class LinkedListNode<T> {
    constructor(public value: T, public next: LinkedListNode<T> | null = null) {}
}

const head = new LinkedListNode("Node_Root", new LinkedListNode("Node_Tail"));

// Loop mechanic: Custom reference pointer pointer traversal hop
let current: LinkedListNode<string> | null = head;
while (current !== null) {
    console.log(`Node runtime content: ${current.value}`);
    current = current.next; // Iterates pointer to next connected memory instance
}
```
