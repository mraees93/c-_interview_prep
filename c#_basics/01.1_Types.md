# C# Reference Guide: Value Types vs. Reference Types & Immutability

### 🧠 Memory & Copying Behavior

| Feature | Value Types | Reference Types |
| :--- | :--- | :--- |
| **Memory Location** | **Stack** (or inline inside a heap object) | **Heap** (with a memory pointer on the stack) |
| **Assignment Copying** | Copies the **actual data values** | Copies the **memory pointer reference** |
| **Nullable by Default** | No (requires `?` modifier) | Yes |
| **Garbage Collector** | Extinguishes immediately when out of scope | Tracks and cleans via collection cycles |
| **Default Types** | `struct`, `record struct`, `int`, `bool`, `enum` | `class`, `record` (`record class`), `string`, arrays |

```csharp
// --- VALUE TYPE COPYING ---
int originalInt = 10;
int copyInt = originalInt; // A completely independent copy is created on the stack
copyInt = 20;              // originalInt remains 10

// --- REFERENCE TYPE COPYING ---
var originObj = new MyClass { Name = "AJ" };
var copyObj = originObj;   // Copies the pointer. Both variables target the exact same heap memory
copyObj.Name = "Sam";      // Modifying copyObj alters originObj.Name to "Sam" as well!
```

### 🛠️ Deep Dive by Language Type

#### 1. Structs (`struct`) ➔ Value Type
Lightweight containers allocated on the stack. Mutable structs can introduce bugs because assignments alter copies instead of the root data container.

```csharp
// BAD PRACTICE: Mutable structs cause unexpected side-effects during copy operations
public struct MutablePoint 
{
    public int X { get; set; } 
}

// GOOD PRACTICE: Fully immutable structural integrity enforced by the compiler
public readonly struct ImmutablePoint 
{
    public int X { get; init; } // 'init' restricts changes exclusively to initialization
    public int Y { get; init; }
    
    public ImmutablePoint(int x, int y) => (X, Y) = (x, y);
}
```

#### 2. Classes (`class`) ➔ Reference Type
The primary heap-allocated component of C# applications, ideal for tracking stateful data, business engines, services, and complex systems.

```csharp
public class CustomerService
{
    private readonly DbContext _context; // Standard reference type pointer storage
    
    public CustomerService(DbContext context) => _context = context;
    
    // Accepts a pointer to a customer instance and directly modifies heap memory
    public void UpdateStatus(Customer customer) => customer.IsActive = true; 
}
```

#### 3. Records (`record`) ➔ It Depends!
A specialized construct optimizing data transfer models with automated **value-based equality** instead of standard reference pointer evaluation.

```csharp
// 1. RECORD CLASS (Reference Type - Default behavior)
// Evaluates to true if property contents match, despite existing as separate heap objects
public record ProductRecord(string SKU, decimal Price); 

// 2. MUTABLE RECORD STRUCT (Value Type)
// Compact positional parameters compiled into standard mutable struct fields
public record struct MutableVector(int X, int Y); 

// 3. IMMUTABLE RECORD STRUCT (Value Type - Highly Recommended)
// Combines raw value type stack memory optimization with unmodifiable immutability
public readonly record struct ImmutableVector(int X, int Y);
```

#### 4. Specialized System Built-ins

```csharp
// Nullable Value Type: Uses a system struct wrapper to safely evaluate null states on the stack
int? nullableAge = null; 

// Strings: Reference types that present value type behavior because they are inherently immutable
string textA = "hello";
string textB = textA; // Pointing to the identical "hello" string literal allocation on the heap
textB = "world";      // Allocates a brand-new "world" string context; textA remains safely unchanged

// Arrays: Even when holding primitives, the parent array container is a reference type on the heap
int[] scores = new int[] { 95, 88, 72 }; 
```

### ⚡ Performance Optimization Features

```csharp
// Non-destructive mutation: Cleanly clones and alters specified fields inside immutable instances
var startingPoint = new ImmutableVector(5, 10);
var movedPoint = startingPoint with { Y = 20 }; // Generates a brand-new struct instance (5, 20)

// 'in' modifier: Optimizes performance by passing value types via reference pointer, eliminating copy overhead
public void ProcessLargeStruct(in ImmutableVector vector)
{
    // vector.X = 10; // Compiler Error: 'in' properties are strictly read-only
    Console.WriteLine(vector.X); 
}
```
